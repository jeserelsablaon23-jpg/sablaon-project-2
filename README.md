# Kabankalan Catholic College Landing Page

A customized Bootstrap-based, responsive, single-page KCC informational website.

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Keep the `assets` folder beside `index.html`.

## Main sections
Home, About KCC, Four Pillars, College Programs, Senior High School Strands,
Campus Life, Admissions, and Contact.

## Important content note
This is a student website project, not an official KCC publication. Course and strand
availability can change. The program list is based on publicly available school and
education-directory information; confirm current offerings, majors, admission dates,
fees, and requirements directly with KCC.

The campus entrance image and seal are linked from publicly available web image sources.
The Campus Life cards use illustrative template photographs and are not represented as
actual KCC event or facility photographs.

## Main files
- `index.html` — KCC landing page
- `assets/css/kcc-custom.css` — custom KCC green-and-gold theme
- `assets/vendor/` — Bootstrap and template dependencies
